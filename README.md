# GitHub Contribution Snake

This repo is meant to generate the snake animation for your GitHub profile.

## Use it

1. Push this repo to GitHub.
2. The workflow already targets `Yuvraj-Malik`.
3. Run the workflow once from the Actions tab.

## Add to your profile README

```md
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://github.com/Yuvraj-Malik/snake/blob/output/snake-cyber.svg" />
  <source media="(prefers-color-scheme: light)" srcset="https://github.com/Yuvraj-Malik/snake/blob/output/snake-neon.svg" />
  <img alt="GitHub contribution snake" src="https://github.com/Yuvraj-Malik/snake/blob/output/snake-cyber.svg" />
</picture>
```
